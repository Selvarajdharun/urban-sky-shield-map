Night-Light Proxy

Satellite-derived night-light information can be used as an indicator of artificial-light distribution. In this prototype, the night-light layer is a conceptual proxy and does not represent direct sky-brightness measurements.

Explainable Factors

Higher urbanisation, infrastructure concentration and artificial-light indicators can conceptually increase predicted pressure. These are relative planning factors, not measured percentages in the current prototype.

AI-Assisted Prediction

A future model can combine geospatial predictors and validated field observations to estimate spatial light-pollution pressure. Model training, accuracy and validation metrics are not claimed in the current prototype.

Validation Roadmap

Future validation can compare model outputs with independent sky-brightness observations, calibrated instruments and geographically distributed field measurements.

AI-Assisted Spatial Planning

The AI layer is designed as a future spatial prediction workflow. Current map values are conceptual planning values and are not presented as trained-model predictions.

Explainability

The system can later expose which spatial factors contribute most strongly to a predicted pressure value, allowing planners to interpret the model instead of receiving only a black-box output.

Future Model

Candidate approaches include gradient-boosted tree models, spatial regression and other explainable machine-learning methods after suitable datasets are assembled.
